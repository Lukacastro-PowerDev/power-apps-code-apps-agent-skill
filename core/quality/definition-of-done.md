# Definition of done

- Scope, datasource, risks, and required evidence are explicit.
- SharePoint internal names and Dataverse logical names are observed or
  generated, never guessed.
- Loading, empty, error, and success states exist for user-facing flows.
- Authorization is least privilege and reviewed with the project matrix.
- Accessibility, internationalization, resilience, build, tests, and report
  checks have evidence.
- Unknowns and limitations are recorded; no secret, tenant-bound identifier,
  or unsupported API claim is introduced.
