# Evidence model

Evidence levels:
- `observed`: directly observed in project artifacts.
- `generated`: generated services/models/contracts.
- `official`: official public documentation.
- `documented`: internal project docs.
- `example`: explicitly fictional examples (`EXAMPLE ONLY`).
- `inferred`: logical inference from stronger evidence.
- `unverified`: statement pending verification.

Every evidence record should include authority, recency, scope, source, and confidence.

For mutable platform details, use: `verify against current official documentation`.
