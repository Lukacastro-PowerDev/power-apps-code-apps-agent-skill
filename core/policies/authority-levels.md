# Authority levels

1. **Project artifact**: observed schema, generated model, or configured service.
2. **Official documentation**: current Microsoft documentation; verify mutable
   details at implementation time.
3. **Repository rule**: this contract, catalog, and approved templates.
4. **Example**: fictional teaching material, always marked `EXAMPLE ONLY`.
5. **Inference**: useful for planning but never sufficient for schema or
   permission decisions.

When levels conflict, stop and resolve the higher-authority source.
