# Universal task lifecycle

1. **Classify** task type, data source, risk, and requested outcome.
2. **Plan context** using deterministic tags and the catalog.
3. **Collect evidence** and record unknowns before changing code.
4. **Decide** architecture, permissions, UX states, and validation gates.
5. **Implement** only against observed/generated contracts.
6. **Validate** build, tests, security, accessibility, and report artifacts.
7. **Review** the final report and retain only intentional project artifacts.

An agent must stop when required schema, permissions, or environment evidence
is missing or conflicting. Templates and fixtures marked `EXAMPLE ONLY` are
not project evidence.
