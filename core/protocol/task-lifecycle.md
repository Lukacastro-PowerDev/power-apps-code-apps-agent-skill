# Task lifecycle protocol

1. Intake and classify task type + datasource.
2. Build context plan with required evidence.
3. Collect and record evidence.
4. Decide authority level and security mode.
5. Plan changes and validations.
6. Implement minimal coherent change.
7. Validate (build/test/docs/security/evals as applicable).
8. Produce universal final report (JSON + Markdown).

If required evidence is missing, stop and ask.
